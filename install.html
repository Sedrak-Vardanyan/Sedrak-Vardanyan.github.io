ARM Keyboard-ի տեղադրում macOS-ում

Եթե macOS-ը ցույց է տալիս, որ չի կարող ստուգել `.pkg` ֆայլը, սա նշանակում է՝ ֆայլը ստորագրված կամ notarized չէ Apple Developer ID-ով։ Տեղադրումը կարելի է շարունակել միայն եթե վստահում եք ֆայլին։

Քայլ առ քայլ՝ պարզ ու հասկանալի ✨

Տեղադրման քայլերը

1

Ներբեռնեք ֆայլը

Սեղմեք Ներբեռնել կոճակը և պահեք ARM_Keyboard.pkg ֆայլը Mac-ի մեջ։

2

Բացեք `.pkg` ֆայլը

Կրկնակի սեղմեք ֆայլի վրա։ Եթե Installer-ը բացվեց՝ շարունակեք սովորական տեղադրումը։

3

Եթե հայտնվում է անվտանգության զգուշացում

Փակեք զգուշացումը, բացեք System Settings → Privacy & Security և ներքևում սեղմեք Open Anyway կամ Allow։

4

Ավարտեք տեղադրումը

Installer-ում սեղմեք Continue → Install, մուտքագրեք Mac-ի գաղտնաբառը և սպասեք մինչև տեղադրումը ավարտվի։

5

Միացրեք ստեղնաշարը

Բացեք Keyboard → Input Sources, ավելացրեք ARM Keyboard-ը և ընտրեք այն վերևի input menu-ից։
